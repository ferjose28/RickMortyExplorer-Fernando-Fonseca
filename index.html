Consumo de la API con JavaScript

El proyecto usa peticiones HTTP GET y transforma la respuesta JSON en tarjetas HTML.

01

Construir la URL

Los filtros del formulario se convierten en parámetros de consulta para el endpoint de personajes.

02

Ejecutar fetch()

Se realiza una solicitud asíncrona, se valida el código HTTP y luego se procesa la respuesta.

03

Convertir a JSON

La respuesta se transforma con response.json() para trabajar con objetos de JavaScript.

04

Renderizar resultados

El DOM se actualiza dinámicamente con nombre, imagen, estado, especie, ubicación y episodios.

Ejemplo usado en el proyecto · async/await JavaScript 
async function cargarPersonajes(url) {
  const respuesta = await fetch(url);

  if (!respuesta.ok) {
    throw new Error(`Error HTTP: ${respuesta.status}`);
  }

  const datos = await respuesta.json();
  renderizarPersonajes(datos.results);
}
